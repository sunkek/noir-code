NoiR Code

Your message, hidden in the shadows of a nocturnal city of rain.

NoiR Code is a QR-like visual encoder where the code is a noir comic panel. It turns text into a scannable, rain-soaked halftone cityscape — a low-resolution engraving of a city whose cell centres carry the data — and decodes it back from an uploaded image, a remote image URL, or a live camera scan.

  • Encode any short text or link into a unique noir panel.
  • Decode by upload, by image URL, or with your camera.
  • Reed–Solomon error correction survives glare, blur and creases.
  • Works from phone photos, screenshots and uneven lighting.

Open noir-code.suncake.xyz in a modern browser to encode and decode interactively. Source on GitHub. Built at suncake.xyz, alongside Vitae Viscera.
